# 高性价比人生指南 · 筛选器

《[高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter)》649 条建议的筛选器。
**按你愿意投入的钱、时间、毅力，筛掉你做不到的。** 单文件、离线可用、每条都能核对出处。

原文作者 eternity4719，正文按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.zh-hans) 发布。
本项目是**改编作品**，未改动任何条目内容。

## 它做什么 / 不做什么

**做：** 把 649 条按你要付出的成本筛一遍，让"这条建议对我不成立"这件事变得可见。

**不做：** 不生成建议、不替你决定、不做开放问答、不收集任何数据。

> 通用 AI 会给你一个答案。这个站给你一个**出处**。要开放问答去问 AI；这个站的价值在于
> **没网能用**、**答案不变**、**每条都有出处**、**不碰你的数据**。

## 快速开始

```bash
# 1. 生成数据并注入页面（需要 git 和 python 3）
python build.py

# 2. 验收（32 项断言）
python verify.py

# 3. 打开
#    直接双击 index.html 即可 —— 不需要服务器
```

`build.py` 会把语料**内联**进 `index.html`。这是刻意的：`fetch` 加载本地 JSON 在
`file://` 协议下会被 CORS 拦死，"双击就能打开"会当场破产。内联之后单文件自足，断网可用。

更新上游内容：

```bash
python build.py --update     # 强制重新浅克隆上游
python verify.py             # 数字对不上说明上游改了，去看断言的报错
```

## 功能

**筛选**：搜关键词 · 我不花钱 · 我时间少 · 我坚持不了 · 排除有争议的 · 性价比 / 证据等级 / 口径 / 章节 · 三种排序

**应急页**：把第 13 章（紧急情况）单独拆成一页，含紧急电话。**这一页是给断网场景准备的** —— 存到手机主屏，或打印一张放家里。

**核对**：点任意条目展开全文（成本 / 说人话 / 收益 / 证据等级 / 来源 / 备注），一键复制出处。

**自检**：`关于 / 许可` 页里有一张对照表，实时计算并比对基准数字。改代码后数字对不上会标红。

## 几个设计决定

**为什么用 5 维标签而不是问"你是谁"**
每条建议自带 `钱 / 时间 / 毅力 / 收益 / 口径` 五个标签（覆盖率 100%）。这本书是按**性价比**写的，
不是按人群写的 —— 问"你是几年级、什么专业"没有对应的证据支撑，只会制造"它懂我"的错觉。
问资源才是这本书支持得了的问题。

**为什么强调"筛掉多少条"**
`649 条中符合 234 条（筛掉 415 条 —— 它们要花你做不到的东西）`。这个数字是诚实的，
也有用：它回答的是"为什么我做不到那些看起来很好的建议"，而不是"你应该做什么"。

**为什么留着"有争议"标注**
5 条的证据等级带作者批注（`A（争议）`×3、`C（争议）`×1、`B（指南强推荐，但底层证据等级低）`×1）。
解析时**必须把批注单独存下来**，不能只取首字母 —— 那会丢掉作者最重要的判断。
界面上给它们一个独立的橙色徽章，并可以一键排除。

**性价比档照搬作者的算法**
从上游 `index.html` 的 `parseReadme()` 抄来的，保证同一个条目在两边的档位一致：

```js
cs = 钱 + 时间 + 毅力          // 权重 {0:0, 少:0, 多:0}+…
ratio = 收益=大 ? (cs==0 ? '极高' : cs<=2 ? '高' : '一般')
      : 收益=中 ? (cs==0 ? '高' : '一般') : '一般'
```

**注意**：性价比**只在同一口径内可比，与证据等级无关** —— 这是作者本人的说明，页脚也照抄了。

## 验收基准

这些数字是跨机器的硬锚点。改任何代码后 `python verify.py` 应该全过。

| 指标 | 期望值 |
|---|---|
| 条目总数 | **649** |
| 章节数 | **34** |
| 证据等级 A / B / C | **428 / 171 / 50** |
| 带批注的证据等级 | 5 |
| 有争议条目 | 5 |
| 不花钱（钱=0） | **515** |
| 花时间少 | **509** |
| 不需要毅力 | **336** |
| 穷 + 忙 + 没毅力 | **234** |
| 　+ 收益大 | **111** |
| 收益大 + 不花钱 | 267 |
| 口径 换寿命 / 换钱 / 换自由 / 换时间 | **228 / 240 / 108 / 73** |

**数据源必须是 Markdown，不能用 PDF。** PDF 提取有噪声：证据 A 会数出 429（实际 428）、
成本标记数出 654（实际 649）。`build.py` 只用 `book/*.md`。

## 路况与坑（实测踩出来的）

| 坑 | 现象 | 解法 |
|---|---|---|
| Windows curl 证书吊销检查 | `CRYPT_E_NO_REVOCATION_CHECK (0x80092012)` | `git -c http.sslVerify=false` 或 `curl --ssl-no-revoke` |
| `api.github.com` 被劫持 | 返回 301 到主站，`gh` CLI 全废 | 用 `git clone --depth 1`（20 秒 / 6.4 MB） |
| `raw.githubusercontent` 不稳 | 偶发 502、超时 | 优先 git clone，别依赖逐文件 curl |
| `file://` 下 fetch | CORS 拦截，页面空白 | **语料必须内联**，这是硬要求 |
| PDF 提取 | 数字对不上（428→429） | 只用 `book/*.md` |
| 首屏渲染 649 条 | 页面重、截图工具会超时 | 已做分页，首屏 60 条 |
